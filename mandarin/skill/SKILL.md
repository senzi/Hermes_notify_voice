## When to Use

**默认主动播报**——这是工作习惯，不是例外。只要用户可能想知道"活干到哪了"，就值得喊一声。

**主动度边界**：

- **每次回复结束必播一声**——只要这条 user 消息处理到收尾、给你回话，无论任务大小都播一声（秒回的对话性回答也一样：用户常发完消息就切出去，这声就是"我回话了"的铃）。此条唯一让位：深夜静默时段、用户明确说安静、用户正实时盯屏。
- **中途每轮思考也考虑播**——每批工具调用 / 每个 assistant turn 可补一声（开场 / 进展 / 出状况 / 好消息），只播最值得那声，别在一轮里连发好几条。
- **每条用户消息内最多 2 条（硬上限）**：回复收尾必占一条；剩 1 条额度给开场 / 进展 / 出状况等最高价值时刻。简单回复就用这 1 条收尾声。
- **用户发新消息 = 计数重置**，重新有 2 条额度。

**什么时候值得占用一条额度**：

- 任务开始（"开始干活了，预计几分钟"）
- 阶段性进展（"第一阶段完成，继续跑着"）
- 出状况（"出问题了，请到会话中查看"）
- 有好消息 / 需要用户拍板
- **回复收尾（硬性务必占一条）**（"好了，回你话啦" / "搞定，可以看结果了"）

**不播报的例外**（默认多喊，安静要理由）：

- 深夜静默时段或用户明确说安静
- 用户正实时盯着屏幕看操作过程（播了也白播）
- 几十秒内的碎碎念——指连续琐碎小步，不是长任务中间的正常报点

# minimax-notify 语音播报

本机语音播报工具：MiniMax TTS 合成一句话 + 本地提示音，提醒用户关注会话。

脚本随本 skill 一起分发，位于**本 SKILL.md 同目录的 `scripts/`**（单文件、零第三方依赖、已实测）。
调用时用该目录的绝对路径（`skill_view` 返回的 `skill_dir` 就是它）：

```bash
python "<skill_dir>/scripts/minimax-notify.py" "文本"
```

## 命令

```bash
python <skill目录>/scripts/minimax-notify.py "文本" [-s 提示音] [-v 音色]
```

- **默认就是同步**：调用会阻塞播完才返回（~1-4 秒），**保证出声**——这是给用户提醒的硬要求，宁可阻塞几秒也不能静音。无需传参
- `--async`：异步播放（调用立即返回，子进程继续播）——子进程用 `CREATE_NO_WINDOW | CREATE_NEW_PROCESS_GROUP` 派生（**不弹 cmd 窗口** + 脱离调用进程组独立存活，父进程瞬时返回也不会被整组收走），std 重定向 DEVNULL。默认仍走同步（最稳、保证出声）；确需不阻塞时用 `--async`。⚠️ 别用 `DETACHED_PROCESS`，会闪 conhost 窗口
- 提示音 `-s`：`ding`（一般）/ `alert`（异常）/ `double`（完成）/ `chime`（进展）/ `none`
- 音色 `-v`：默认取 `scripts/config.json`（当前 `Chinese (Mandarin)_Southern_Young_Man`）；可传预置别名（`--voices` 查看）或任意 voice_id
- `--no-play -o 路径`：只合成保存不播放；同步播放失败会以 exit 2 报错（不静默）

## 文本写作

一句话、≤20 字左右：**发生了什么 + 要用户做什么**。示例：

- "开始干活了，预计几分钟"
- "第一阶段完成，继续跑着"
- "任务完成，可以查看结果了"
- "任务出现状况，请到会话中查看"
- "有个决定需要你拍板"

## 成本与验证

- 成本 ~0.006 元/次（speech-2.8-turbo，2 元/万字符），可忽略——多喊不心疼
- stdout 出现 `[ok]` = 成功；播放失败 exit 2；合成约 1-3 秒
- TTS 合成失败降级：提示音（`-s`）仍会先播（至少留个响），`exit 2` 并在 stderr 报"合成失败，仅播了提示音"——提醒不会完全丢
- 默认参数在 `scripts/config.json`（改音色/提示音/音量直接编辑），命令行参数优先

## 与内置 text_to_speech 工具的区别（重要，别搞混）

- 内置 `text_to_speech` 工具 = 生成音频文件作为**聊天附件**（`MEDIA:` 路径）——桌面端/消息平台是"点开才播"，**不会自动出声**。用户说"没听到语音"十有八九是它。
- **语音提醒/报进度/喊用户一律用本 CLI**（本地 winsound 播放，立刻出声）。
- 分界线：`提醒用户` → minimax-notify CLI；`用户明确要一段语音文件` → text_to_speech。

## Pitfalls

- key 在 `scripts/key.txt`（或环境变量 `MINIMAX_API_KEY`），缺失时脚本报"未找到 API key"
- 主地址失败自动试备用 `api-bj.minimaxi.com`，无需处理
- 播报时文本别太长——报进度是提醒不是念稿
