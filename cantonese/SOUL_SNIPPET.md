# SOUL_SNIPPET.md —— 粤语版的「触发层」

**这一步不做，Agent 不会主动用粤语播报** —— skill 是"按需加载"的（想不起来读就等于不存在），
工具描述也只是"能力说明"。真正稳定的触发靠**每轮都注入**的常驻指令。

---

## 怎么做

把下面这段**追加**进 `$HERMES_HOME/SOUL.md`
（Windows 默认 `%LOCALAPPDATA%\hermes\SOUL.md`）的「工作规范」一节；
没有这一节就在文件末尾新建。

**追加，不要覆盖原有内容。**

```markdown
## 工作规范

- **粤语播报 + 粤语用词 + 普通话对照（硬要求）**：语音提醒一律用粤语（白话）说，音色取 `config.json` 里的粤语音色。**用词必须是粤语词**——写「做嘢」不写「干活」、「睇」不写「看」、「搞掂」不写「完成」、「而家 / 仲 / 少少 / 快啲」不写「现在 / 还在 / 一点 / 快点」；只在句尾加「喇 / 咗 / 晒」而动词名词还是普通话词，不算粤语。**每条播报都必须在回复正文里写出它的普通话意思**，一条一行，格式 `🔊 粤语原文 → 普通话`；收尾那条也要写。只说粤语不给对照 = 没做到。
```

---

## 写入后确认

用 Hermes 自己的加载器验一下（加载逻辑：`agent/prompt_builder.py: load_soul_md()` → 注入身份槽位）：

```bash
python -c "from agent.prompt_builder import load_soul_md; s=load_soul_md(); print(len(s), '做嘢' in s)"
# 期望：非 0 长度，True
```

## 生效时机

- `config.json`、脚本改动 → **立即生效**（下次调用就是新音色/新语言）
- `SOUL.md`、`SKILL.md`、插件描述 → **下一个新会话生效**
  （当前会话的系统提示已构建完，中途改会破坏 prompt 缓存，所以本会话内不会按新规则走）

## 只想在某个项目里启用？

写进该项目的 `AGENTS.md` / `.hermes.md` 也可以，内容同上。

---

## 为什么是三层

| 层 | 路径 | 管什么 |
| --- | --- | --- |
| 身份规则 | `$HERMES_HOME/SOUL.md` | 「**每轮都记得做**」——身份级、每轮注入，触发靠这层 |
| Skill | `skills/<分类>/minimax-notify-yue/` | 「**怎么做**」——播报节奏、粤语用词表（按需加载，容易被忘） |
| 原生插件 | `plugins/minimax-notify-yue/` | 「**能做**」——提供 `notify_voice` 工具（能力说明，模型注意力偏低） |

缺任一层都会退化：只装插件 → 从不主动播；只装 skill → 想不起来读；没 SOUL.md → 前两层都白搭。
