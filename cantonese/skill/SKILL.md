## When to Use

**默认主动播报**——这是工作习惯，不是例外。只要用户可能想知道"活干到哪了"，就值得喊一声。

**主动度边界**：

- **每次回复结束必播一声**——只要这条 user 消息处理到收尾、给你回话，无论任务大小都播一声（秒回的对话性回答也一样：用户常发完消息就切出去，这声就是"我回话了"的铃）。此条唯一让位：深夜静默时段、用户明确说安静、用户正实时盯屏。
- **中途每轮思考也考虑播**——每批工具调用 / 每个 assistant turn 可补一声（开场 / 进展 / 出状况 / 好消息），只播最值得那声，别在一轮里连发好几条。
- **每条用户消息内最多 2 条（硬上限）**：回复收尾必占一条；剩 1 条额度给开场 / 进展 / 出状况等最高价值时刻。
- **用户发新消息 = 计数重置**，重新有 2 条额度。

**什么时候值得占用一条额度**：

- 任务开始（"开始做嘢喇，等几分钟"）
- 阶段性进展（"第一阶段搞掂，继续跑住"）
- 出状况（"出咗事，快啲入会话睇下"）
- 有好消息 / 需要用户拍板（"有件事等你话事"）
- **回复收尾（硬性务必占一条）**（"搞掂晒，睇得结果喇"）

**不播报的例外**（默认多喊，安静要理由）：

- 深夜静默时段或用户明确说安静
- 用户正实时盯着屏幕看操作过程（播了也白播）
- 几十秒内的碎碎念——指连续琐碎小步，不是长任务中间的正常报点

# minimax-notify（粤语学习者版）

本机语音播报工具：MiniMax TTS 合成**粤语（白话）**一句话 + 本地提示音，提醒用户关注会话。

脚本随本 skill 一起分发，位于**本 SKILL.md 同目录的 `scripts/`**（单文件、零第三方依赖、已实测）。
调用时用该目录的绝对路径（`skill_view` 返回的 `skill_dir` 就是它）：

```bash
python "<skill_dir>/scripts/minimax-notify.py" "文本"
```

## 三条硬规则（缺一不可）

1. **播报一律用粤语（白话）**：音色取 `scripts/config.json`（`Cantonese_GentleLady`），
   `language_boost=Chinese,Yue` 强制走粤语读音通道——不传就是普通读音，不是粤语。
2. **用粤语词，不用普通话词**：光把句尾改成「喇 / 咗 / 晒」而动词名词还是普通话词，**不算粤语**。
3. **每条播报都要在回复正文里写出普通话对照**：格式 `🔊 粤语原文 → 普通话`，收尾那条也一样。
   **只说粤语不给对照 = 没做到。**

## 粤语用词对照（写播报时查这张表）

| 别写（普通话） | 要写（粤语） |
| --- | --- |

| 看 / 查看 | 睇 / 睇下 |
| 完成 / 搞定 | 搞掂 / 搞掂晒 |
| 现在 | 而家 |
| 还在 / 仍然 | 仲 |
| 一点 / 稍微 | 少少 |
| 快点 | 快啲 |
| 出问题 | 出咗事 / 有啲唔妥 |
| 没问题 | 冇问题 |

| 稍等 | 等阵 |

| 请 | 不用，直接说事（「麻烦你」可） |

## 命令

```bash
python <skill目录>/scripts/minimax-notify.py "文本" [-s 提示音] [-v 音色] [--lang 语言]
```

- **默认就是同步**：播完才返回（~1-4 秒），**保证出声**；`--async` 可切异步不阻塞
- **通过 `notify_voice` 工具调用时是后台的**：发起即返回（~4 ms），播报自己播完，不会卡住你的思考或输出；只有传 `sync=true` 才等播完拿回执
- 提示音 `-s`：`ding`（一般）/ `alert`（异常）/ `double`（完成）/ `chime`（进展）/ `none`
- 音色 `-v`：默认取 `scripts/config.json`；粤语可用别名
  `yue_gentle`（默认）/ `yue_kind` / `yue_cute` / `yue_playful` / `yue_host_f` / `yue_host_m`
- `--lang`：`Chinese,Yue`（默认，粤语）/ `Chinese` / `auto`；**留空 = 按普通读音念**（那就不是粤语了）
- `--no-play -o 路径`：只合成保存不播放

## 播报 → 普通话对照 例句

| 播报（音频，粤语） | 回复正文里的对照 |
| --- | --- |
| 开始做嘢喇，等几分钟 | 开始干活了，预计几分钟 |
| 第一阶段搞掂，继续跑住 | 第一阶段完成，继续跑着 |
| 搞掂晒，睇得结果喇 | 全部做完了，可以看结果了 |
| 出咗事，快啲入会话睇下 | 出问题了，快点到会话里看看 |
| 有件事等你话事 | 有个决定需要你拍板 |
| 收到，我睇睇先 | 收到，我先看看 |

## 成本与验证

- 成本 ~0.006 元/次（speech-2.8-turbo，2 元/万字符），可忽略
- stdout 出现 `[ok:sync]` = 成功；TTS 失败降级为"只响提示音"+ exit 2，不静默
- 默认参数在 `scripts/config.json`（音色 / 提示音 / 音量 / 语言），命令行参数优先

## 与内置 text_to_speech 工具的区别（重要，别搞混）

- 内置 `text_to_speech` = 生成音频**附件**（`MEDIA:` 路径），**不会自动出声**
- **语音提醒/报进度一律用本 CLI**（本地 `winsound` 播放，立刻出声）

## Pitfalls

- **发音是普通话、不是粤语** → 没传 `language_boost`；只认 `Chinese` / `Chinese,Yue` / `auto`，
  写 `Chinese,Cantonese` 或 `yue` 会报 `2013 invalid params`
- **`接口错误 2054: voice id not exist`** → 该账号只有 6 个粤语音色可用（见上表别名）；
  `Cantonese_Male_1`、`Cantonese_News_Anchor`、`female-yue-1` 等**全部不存在**
- **音色听着别扭** → 拿普通话书面句喂粤语音色；播报文本必须用粤语口语词
- **工具调用是普通话、命令行是粤语** → 两个 `config.json` 只改了一个；
  `scripts/config.json` 与插件目录的 `config.json` 必须同时改
- key 在 `scripts/key.txt`（或环境变量 `MINIMAX_API_KEY`），缺失时脚本报"未找到 API key"
